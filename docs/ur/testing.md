# Full Stack FastAPI Template { #full-stack-fastapi-template } فُل اسٹیک  FastAPI  ٹیمپلیٹ

ٹیمپلیٹس عام طور پر ایک مخصوص سیٹ اپ کے ساتھ آتے ہیں، لیکن انہیں لچکدار اور حسبِ ضرورت بنانے کے لیے ڈیزائن کیا گیا ہے۔ اس کی بدولت آپ اپنے پراجیکٹ کی ضروریات کے مطابق انہیں تبدیل اور ڈھال سکتے ہیں، جو انہیں شروعات کے لیے ایک بہترین نقطہ بناتا ہے۔ 🏁

آپ شروعات کے لیے یہ ٹیمپلیٹ استعمال کر سکتے ہیں، کیونکہ اس میں ابتدائی سیٹ اپ، سیکیورٹی، ڈیٹا بیس اور کچھ  API  اینڈ پوائنٹس پہلے سے ہی تیار ہیں۔

گٹ ہب ریپوزٹری**:** [فُل اسٹیک FastAPI ٹیمپلیٹ](https://github.com/fastapi/full-stack-fastapi-template)

## Full Stack FastAPI Template - Technology Stack and Features { #full-stack-fastapi-template-technology-stack-and-features } فُل اسٹیک  FastAPI  ٹیمپلیٹ - ٹیکنالوجی اسٹیک اور خصوصیات

- ⚡ پائتھون بیک اینڈ  API  کے لیے [**FastAPI**](https://fastapi.tiangolo.com)۔
  - 🧰 پائتھون  SQL  ڈیٹا بیس آپریشنز (ORM) کے لیے [SQLModel](https://sqlmodel.tiangolo.com)۔
  - 🔍 ڈیٹا ویلیڈیشن اور سیٹنگز مینجمنٹ کے لیے [Pydantic](https://pydantic.dev/docs/)، جسے  FastAPI  خود استعمال کرتا ہے۔
  - 💾  SQL  ڈیٹا بیس کے طور پر [PostgreSQL](https://www.postgresql.org)۔
- 🚀 فرنٹ اینڈ کے لیے [React](https://react.dev)۔
  - 💃  TypeScript ،  hooks ،  Vite  اور جدید فرنٹ اینڈ اسٹیک کے دیگر اجزاء استعمال کرتے ہوئے۔
  - 🎨 فرنٹ اینڈ کمپوننٹس کے لیے [Tailwind CSS](https://tailwindcss.com) اور [shadcn/ui](https://ui.shadcn.com)۔
  - 🤖 خودکار طور پر جنریٹ ہونے والا فرنٹ اینڈ کلائنٹ۔
  - 🧪 اینڈ ٹو اینڈ ٹیسٹنگ کے لیے [Playwright](https://playwright.dev)۔
  - 🦇 ڈارک موڈ سپورٹ۔
- 🐋 ڈیویلپمنٹ اور پروڈکشن کے لیے [Docker Compose](https://www.docker.com)۔
- 🔒 ڈیفالٹ کے طور پر محفوظ پاس ورڈ ہیشنگ۔
- 🔑  JWT  (JSON Web Token) کے ذریعے تصدیقِ ہویت۔
- 📫 ای میل کے ذریعے پاس ورڈ ریکوری۔
- ✅ [Pytest](https://pytest.org) کے ساتھ ٹیسٹس۔
- 📞 ریورس پراکسی / لوڈ بیلنسر کے طور پر [Traefik](https://traefik.io)۔
- 🚢  Docker Compose  کا استعمال کرتے ہوئے ڈیپلائمنٹ ہدایات، جن میں یہ بھی شامل ہے کہ خودکار  HTTPS  سرٹیفکیٹس کے لیے فرنٹ اینڈ  Traefik  پراکسی کیسے سیٹ کیا جائے۔
- 🏭  GitHub Actions  پر مبنی  CI  (continuous integration) اور  CD  (continuous deployment)۔
